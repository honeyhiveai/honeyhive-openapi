# HoneyHive OpenAPI Specifications

> **Preview:** These specs are a preview for an upcoming major release of the HoneyHive API. Endpoints, schemas, and behavior may change before the stable release. Do not depend on these specs for production integrations until the release is finalized.

The official [OpenAPI](https://www.openapis.org/) specifications for the HoneyHive APIs: the [Data Plane API](https://api.dp1.us.honeyhive.ai) (event ingestion, evaluation, and observability data) and the [Control Plane API](https://api.cp.us.honeyhive.ai) (projects and alerts).

## Files

| [`data_plane_openapi.json`](data_plane_openapi.json) | JSON | Same specification in JSON format |

## Usage

### API Documentation

These specs power the API reference at [docs.honeyhive.ai](https://docs.honeyhive.ai).

### SDK Generation

Generate a client in any language using [OpenAPI Generator](https://openapi-generator.tech/) or [Speakeasy](https://www.speakeasy.com/). The examples below build a Data Plane client; substitute `control_plane_openapi.yaml` to generate a Control Plane client instead:

```bash
# OpenAPI Generator
openapi-generator-cli generate -i data_plane_openapi.yaml -g python -o ./honeyhive-python

# Speakeasy
speakeasy generate sdk -s data_plane_openapi.yaml -o ./honeyhive-sdk -l python
```

### Raw URLs

Reference the specs directly via GitHub raw URLs:

```
https://raw.githubusercontent.com/honeyhiveai/honeyhive-openapi/main/data_plane_openapi.yaml
https://raw.githubusercontent.com/honeyhiveai/honeyhive-openapi/main/data_plane_openapi.json
https://raw.githubusercontent.com/honeyhiveai/honeyhive-openapi/main/control_plane_openapi.yaml
https://raw.githubusercontent.com/honeyhiveai/honeyhive-openapi/main/control_plane_openapi.json
```

### Postman

Import `data_plane_openapi.json` or `control_plane_openapi.json` into [Postman](https://www.postman.com/) to explore the APIs interactively.

## How This Repo Is Updated

This repository is automatically updated by CI in the HoneyHive platform repo. Both specs are regenerated from source and pushed here in both YAML and JSON formats.

`CHANGELOG.md` entries are generated deterministically with [oasdiff](https://github.com/oasdiff/oasdiff) by diffing the previously published spec against the new one (`oasdiff changelog --format markdown`), so re-running the same command on the same inputs always produces byte-identical output. It currently covers the Data Plane API spec.
